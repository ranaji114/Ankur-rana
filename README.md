## ✨ About This Project

**Ankur Rana** is a premium editorial-style personal website built to bring together an author's **books, research, ideas, writing, and digital presence** in one focused experience.

Instead of treating a portfolio like a traditional developer resume, this project is designed around an **author identity** — calm typography, structured storytelling, curated books, research themes, reading paths, and carefully presented content.

> **Built around ideas worth reading, exploring, and remembering.**

## 🎨 Design Philosophy

The visual direction follows an **editorial luxury** aesthetic:

- 📰 Editorial composition
- ✒️ Serif-led headline typography
- 🧾 Minimal information hierarchy
- 🎞️ Motion-based transitions
- 🪶 Generous whitespace
- 📐 Consistent visual rhythm
- 📱 Responsive layouts

## ⚡ Motion & Interaction

The project uses modern motion primitives so transitions feel intentional rather than distracting:

- 🎬 Motion-based UI transitions
- 🖱️ Hover and focus feedback
- 📜 Scroll-aware presentation
- 🪄 Micro-interactions
- 🧭 Smooth navigation transitions
- 📚 Animated content presentation

> **Motion should support the story, not compete with it.**

---

## 🧱 Architecture

The project follows a content-driven structure that separates editorial data from presentation:

```text
src/
├── app/
├── data/
│   └── content.ts
└── components/

public/
└── assets/
    ├── author/
    └── books/
```

Most content can be maintained through:

```txt
src/data/content.ts
```

This includes author information, books, featured books, reading paths, research topics, publication timeline, social links, and newsletter configuration.

## 🚀 Getting Started

### 1. Clone

```bash
git clone https://github.com/ranaji114/Ankur-rana.git
cd Ankur-rana
```

### 2. Install

```bash
npm install
```

### 3. Run locally

```bash
npm run dev
```

Open `http://localhost:3000`.

### 4. Build

```bash
npm run build
```

### 5. Start production server

```bash
npm start
```

### 6. Lint

```bash
npm run lint
```
