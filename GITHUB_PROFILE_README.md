## 🚀 Featured Flagship Projects

### 01 · [Ezra Programming Language & VM](https://github.com/ranaji114/Ezra)
> **A readable, human-centric scripting language and stack-based Bytecode Virtual Machine built in Rust.**

<div align="center">

```
 ┌────────────────┐      ┌───────────────┐      ┌──────────────┐      ┌────────────────┐      ┌──────────────────┐
 │  Source (.ez)  │ ───> │  Rust Lexer   │ ───> │  AST Parser  │ ───> │  Bytecode VM   │ ───> │  Runtime Output  │
 │  Readable Code │      │  (Zero-Copy)  │      │  (Tree Gen)  │      │  (19 Opcodes)  │      │  (0.42ms Exec)   │
 └────────────────┘      └───────────────┘      └──────────────┘      └────────────────┘      └──────────────────┘
```

</div>

* **Architecture**: Hand-crafted zero-copy lexical scanner, AST grammar parser, bytecode compiler with constant pools, and virtual machine.
* **Toolchain**: Dedicated CLI toolchain for building, formatting, and executing scripts; custom VS Code extension with grammar highlighting.
* **Interactive IDE**: Web-based playground compiling and running Ezra bytecode directly in the browser.
* **Links**: [📦 GitHub Repo](https://github.com/ranaji114/Ezra) · [🌐 Live Documentation & Web IDE](https://ezra-lang.vercel.app)

> **Full-stack educational platform for a real coaching institute in Kadipur, UP (PCM/B Classes 6th–12th).**

* **Digital Admissions**: Multi-step student enrollment capturing parent details, target batch, and academic records into Supabase PostgreSQL.

* **Links**: [🌐 Live Website](https://shri-krishna-coaching-center.vercel.app/) · [📦 GitHub Repo](https://github.com/ranaji114/Shri-Krishna-coaching-center)
